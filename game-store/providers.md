# Open Storyboard / Game-Asset Providers

- OpenGameArt: 2D/3D game art and related free/open assets. Check each item's license.
- Poly Haven: CC0 models, HDRIs and textures. Use the official API where appropriate and follow its current API terms.
- Smithsonian Open Access: qualifying public/CC0-designated 2D/3D collection records.

## Import contract

`source_url + license + attribution + retrieval_time + sha256 + importer_version` are stored with every cached item.

No crawler should bypass access controls, robots directives, DRM, rate limits, paywalls or site terms. Official APIs/download endpoints are preferred over scraping.
