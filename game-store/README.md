# BizXtreme 2D/3D/4D Storyboard Store

Engine-neutral catalog for importing legally reusable game/storyboard content into Unity, WebGL/Three.js, Godot, Unreal-compatible pipelines and other adapters.

## Formats

- 2D: PNG/JPEG/WebP/TIFF/SVG where safely supported, sprites, tiles, UI and storyboard frames
- 3D: glTF/GLB, OBJ, FBX and engine-specific import boundaries
- 4D: time-indexed scene/state sequences built from 2D/3D frames, transforms, cameras, lights and optional volumetric samples
- Storyboards: scenes, dialogue, quests, level layouts, camera tracks and prototype game templates

## Store model

Items can be `free`, `donation`, or `low_price`. Paid content is represented as a checkout intent. Crypto payment is not silently executed: the user must approve a transaction in a supported wallet/provider.

## License gate

Publicly reachable does not mean freely reusable. Every imported item records source, license, attribution, version and SHA-256. Automatic ingestion is limited to provider-approved APIs/downloads and assets whose license permits the intended use.

Preferred open collections include OpenGameArt, Poly Haven and qualifying Smithsonian Open Access records.
