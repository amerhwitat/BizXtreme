# BizXtreme Payment Configuration

Canonical Ethereum receiving address:

`0x0B4fF3fc6AE19fAF9A0d2628a646ABD9636B1162`

The address is configuration data only. No private keys are stored in the repository and no code may execute an unattended transfer or swap. Production payments and swaps require explicit authorization from the user's wallet/payment provider.

Game implementations should use the shared payment interfaces for quotes, user-authorized swaps, transaction verification, and settlement ledger records. Development builds should use deterministic simulated payments.
