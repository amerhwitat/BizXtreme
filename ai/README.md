# BizXtreme AI Platform

AI capabilities are organized by discipline rather than by one monolithic model: ML, DL, RL, Symbolic AI, Computer Vision and NLP.

The same job contract can be consumed by the Python, JavaScript/TypeScript, Java, Rust, C/C++ and mobile application layers already present in the repository. Provider-specific integrations are adapters, not copied upstream projects.

Recommended open-source integration families include scikit-learn, PyTorch, Gymnasium, Stable-Baselines3, SymPy, OpenCV, spaCy, Hugging Face Transformers, MLflow, Kubeflow, ONNX and Apache TVM.
