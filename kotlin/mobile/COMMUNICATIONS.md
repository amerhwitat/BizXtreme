# BizXtreme Mobile Communications

BizXtreme Mobile uses the same authenticated conversation contract as BizX: conversation ID, sender ID, monotonic sequence and SHA-256 payload integrity. WebRTC is the media boundary for voice/video, while Android runtime permissions govern microphone and camera access.

The design supports synchronized game/business conversations, presence and media-session state without enabling arbitrary remote command execution. Use the ChimeraIIOS portfolio mobile builder for reproducible APK builds.
