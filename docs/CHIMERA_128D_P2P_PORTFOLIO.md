# Chimera 128D + P2P Portfolio Integration

BizXtreme is a multi-runtime application/game participant in the Chimera portfolio.

## 128D state

World, player and social state can expose geometry, time, observer/perspective, light/material response, events, objects, properties and interaction rules, with an extensible perception/cognition/vector layer.

## P2P

Peer synchronization is opt-in and authenticated. Supported logical operations are hello, request, response, publish, snapshot, delta and acknowledgement. Implementations validate peer identity/capabilities, sequence numbers, payload hashes and optional signatures. WebSocket/WebRTC may provide browser transport without changing the logical contract.

The protocol excludes unsolicited scanning, credential/private-key exchange, arbitrary executable transfer and remote command execution.

## Languages

VC++, C#, Node.js, Java, Python, JavaScript, TypeScript, Unity/C# and WebGL components remain native while consuming shared JSON conformance contracts.
